# 就活管理システム
求人票をコピペするだけで就活の進捗管理ができるシステム。データベースはカレンダーやトップのリマインダーに連動し、就活のステータスやスケジュールが一目で確認できます。仕事内容と希望する方向性のマッチ度も確認することができます。

メインの言語はReact + Viteです。テキストと画像からのデータ抽出・仕分けはGemini APIで行い、JavaScriptの条件演算子・配列メソッド（some / includes）を使い、キーワードがマッチすれば加点式で採点しています。

## 課題と解決策

**課題**
求人サイトによって載っている情報が異なるため、複数のサイトを並行して使用することになる。
サイトが増えれば増えるほど、どのサイトから応募したのかわからなくなる。
その情報を横断するためにExcelやスプレッドシートで管理することもできるが、一つひとつコピペで入力するのは大きな手間になる。

**解決策**
AIに情報を自動で感知・分類させ、できるだけシンプルな工程でデータベースを作成できるシステムを作る。
募集要項のテキストやスクショを貼るだけで自動に必要事項を分類し表示できるようにした。
そのデータベースは見せ方を工夫した。バックで情報のセグメントを行い、どこで見せるのかを設定するすることでよりわかりやすいシステムになる。

## 主要機能

### 01 求人票をコピーするだけでAIが自動分類

![求人票をコピーするだけでAIが自動分類](./gif01.gif)

求人ページでCtrl+A → コピー → ペーストするだけ。
Geminiが求人票のテキストを解析し、会社名・職種・給与・勤務地などの項目に自動で分類する。選択作業は一切不要。

テキストだけでなく、求人票のスクリーンショットからも抽出可能。
読み込めない情報や特記事項があれば、手入力もできる。

---

### 02 登録したらカレンダーに自動表示・面接をハイライト

![登録したらカレンダーに自動表示・面接をハイライト](./gif02.gif)

面接日程を登録すると、上部のカレンダーに自動で表示される。
1週間以内に迫った面接はハイライト表示され、見落としを防ぐ。

---

### 03 進捗を選ぶと、システムが一緒に喜ぶ

![進捗を選ぶと、システムが一緒に喜ぶ](./gif03.gif)

一次通過・内定などのステータスを選ぶと、お祝いメッセージが流れる。

就活は「落ちる・迷う・断る」という感情的に消耗する場面の連続。
だからシステムが事務的に記録するだけでなく、ユーザーのどんな判断も肯定する言葉を返す設計にした。

内定辞退を選んだときのメッセージ：**「よく判断した！おめでとう！」**
この設定にした意図は、就職活動は大変な心労や労力がかかっていることから。
ユーザーに対してポジティブなメッセージを発信することで、心のケアも兼ねている。

### その他の機能

**オンライン面接URLをワンクリックで開く**
面接形式でオンラインを選択すると、Zoom・Microsoft Teams・Google Meet のURLを登録できる。
登録したURLはカレンダーと「1週間以内に予定されている面接」欄に表示され、クリックするとそのまま接続できる。

**求人サイトを自動判定**
14社の求人サイトのURLをあらかじめ登録済み。URLのパターンをAIに学習させているため、募集要項のURLを貼るだけで「マイナビ転職」「doda」「doda X」などのサイト名を自動で判別して表示する。

**企業の場所をGoogleマップで確認**
募集要項のテキストまたはスクリーンショットから、企業の勤務先住所（本社ではなく勤務先）を自動で読み込む。その住所にGoogleマップが自動で紐づき、面接場所を地図で確認できる。

**ステータスを表から直接変更できる**
書類選考中・一次面接・最終結果待ちなど、就活中はステータスが頻繁に変わる。変更頻度が低い情報は「編集」ボタンから変更できるが、ステータスや面接の日時など頻繁に変わる情報はデータベースの表上で直接変更できる。

**データベースをステータスでタブ分け表示**
進行中・内定・終了（辞退・不採用）・全件表示のタブに分けて管理できる。

**CSVでデータをダウンロード**
管理しているすべての求人情報をCSVでダウンロードできる。
